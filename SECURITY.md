# Security

## Reporting a problem

If you find a security problem in KanbanHub, please **don't open a public issue**.
Report it privately instead:

- through GitHub: [Report a vulnerability](https://github.com/danik3422/kanban-flow/security/advisories/new);
- or by email: **mr.siloacd@gmail.com**.

Please include what you found, how to reproduce it and what an attacker could do with it.
You will get a reply within a few days. Once it is fixed, you'll be credited in the
release notes if you want.

## Supported versions

Only the latest code on `main` and the hosted version at
[kanbanhub.app](https://kanbanhub.app) get security fixes. If you run your own copy,
keep it updated as described in [SELF_HOSTING.md](SELF_HOSTING.md#update).

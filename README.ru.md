## Что это

KanbanHub — доска задач в духе Trello. Вы создаёте доску, добавляете списки вроде
«Сделать», «В работе» и «Готово» и перетаскиваете карточки по мере продвижения работы.
Все, кого вы пригласили, видят изменения в ту же секунду.

Приложение сделано так, чтобы быть тихим и быстрым: ничего не мигает, ничего не
навязывают, данные о вас не продаются и не отслеживаются. Весь код открыт под лицензией
MIT — его можно читать, менять и запускать на своём компьютере или сервере, даже вовсе
без интернета.

## Возможности

**Доски и карточки**
- Доски со списками и карточками; перетаскивание мышью или пальцем.
- У карточек есть участники, цветные метки, даты начала и срока, приоритет, обложка,
  описание с форматированием, чек-листы, вложения и комментарии.
- Учёт времени: запустите таймер или добавьте время вручную, задайте оценку.
- Фильтр по участнику, метке, приоритету или дате. Копирование карточек, списков и целых досок.
- Фон доски из библиотеки фото, цветом или вашей картинкой — с выбором позиции,
  размытием, затемнением, яркостью и насыщенностью.

**Совместная работа**
- Приглашения по ссылке или по почте; роли владельца, администратора и участника.
- Обновления в реальном времени: кто-то двигает карточку — вы видите, как она едет.
  Видно, кто сейчас онлайн.
- Уведомления в приложении и, если хотите, на почту: сразу или сводкой.
- Публичная ссылка на доску только для просмотра.

**Ваш день**
- **Мои задачи** — все назначенные вам карточки со всех досок, сгруппированные по датам.
- **Календарь** — карточки на датах сроков; перетащите карточку на другой день, чтобы перенести.
- Поиск по всему через <kbd>⌘</kbd> <kbd>K</kbd> / <kbd>Ctrl</kbd> <kbd>K</kbd>.

**И всё остальное**
- Английский, украинский и русский языки.
- Светлая, тёмная или системная тема.
- Работа без сети: если связь пропала, приложение всё равно откроется и покажет всё,
  что уже было загружено, и честно скажет, что изменения подождут интернета.
- Вход по почте и паролю, через Google или по ключу доступа (passkey); список устройств
  и выход с других устройств.

## Начать пользоваться

Проще всего — готовая версия: **[kanbanhub.app](https://kanbanhub.app)**.
Создайте аккаунт, доску и пригласите команду. Это бесплатно.

## Своя копия в Docker

KanbanHub можно запустить на ноутбуке, домашнем сервере или любом VPS. Нужен только
[Docker](https://docs.docker.com/get-docker/). Интернет не обязателен: ни почтовый сервис,
ни облачное хранилище, ни сторонние аккаунты не нужны.

```sh
git clone https://github.com/danik3422/kanban-flow.git
cd kanban-flow
docker compose up -d
```

Откройте **http://localhost:8080** и создайте первый аккаунт. Готово.

<img src="docs/images/self-hosting.jpg" alt="Инструкция по установке на kanbanhub.app" width="100%">

Полная инструкция пошагово объясняет:

- как открыть приложение с других устройств в вашей сети;
- как подключить свой домен с HTTPS;
- как установить на компьютер совсем без интернета;
- как настроить почту (по желанию), кто может регистрироваться, и команды администратора,
  например сброс пароля;
- как обновлять, делать резервные копии и восстанавливать, все настройки и решение проблем.

Читайте её на сайте — **[kanbanhub.app/self-hosting](https://kanbanhub.app/self-hosting)**
(есть русская версия) или в репозитории — **[SELF_HOSTING.md](SELF_HOSTING.md)**.

## Работа с кодом

Нужны **Node.js 24** и npm. MongoDB для разработки не обязательна: сервер умеет
поднимать временную базу в памяти.

**1. Скачайте код и установите пакеты**

```sh
git clone https://github.com/danik3422/kanban-flow.git
cd kanban-flow
npm install
npm --prefix backend install
npm --prefix frontend install
```

**2. Создайте файлы настроек**

```sh
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env
```

В `backend/.env` впишите в `JWT_SECRET` любую случайную строку от 32 символов. Затем
либо укажите в `MONGO_URI` свою MongoDB (она должна работать как replica set), либо
поставьте `ALLOW_MEMORY_DB=true`, чтобы использовать временную базу в памяти. Всё
остальное — почта, Cloudinary, Firebase, Unsplash — необязательно, можно оставить пустым.

**3. Запустите**

```sh
npm run dev
```

Приложение откроется на **http://localhost:5173**, API работает на порту 5001.
Оба перезагружаются при сохранении файла.

**4. Проверьте изменения**

```sh
npm --prefix frontend run lint    # стиль кода
npm --prefix frontend test        # юнит-тесты веб-приложения
npm --prefix backend test         # тесты API (с базой в памяти)
npm --prefix frontend run build   # продакшн-сборка
```

Сквозные браузерные тесты лежат в `e2e/`: `npm run e2e:start`, затем `npm run e2e:flows`,
затем `npm run e2e:stop`.

## Структура проекта

```text
kanban-flow/
├── frontend/              веб-приложение (React + Vite)
│   └── src/
│       ├── app/           оболочка: маршруты, боковая и верхняя панели, баннер офлайна
│       ├── pages/         по файлу на страницу
│       ├── features/      код по разделам: board, boards, calendar, my-tasks,
│       │                  team, notifications, settings, auth, site, ...
│       ├── ui/            общие компоненты и дизайн-токены
│       ├── i18n/          тексты на английском, украинском и русском
│       ├── lib/           клиент API, кеш, офлайн-режим, утилиты
│       ├── store/         состояние приложения (zustand)
│       └── sw/            service worker для работы без сети
├── backend/               API (Express + MongoDB + Socket.IO)
│   ├── routes/            адреса → обработчики
│   ├── controllers/       обработчики запросов
│   ├── services/          общая логика: доступы, уведомления, файлы
│   ├── models/            модели базы данных
│   ├── validation/        схемы запросов
│   ├── middlewares/       авторизация, CSRF, лимиты запросов
│   ├── realtime/          живые обновления и присутствие
│   ├── emails/            шаблоны писем и рассылки
│   ├── scripts/           миграции и команды администратора
│   └── test/              тесты API
├── e2e/                   браузерные тесты (Playwright)
├── docker/                скрипт запуска контейнера
├── Dockerfile             один образ: API + собранное веб-приложение
├── docker-compose.yml     приложение и MongoDB, готово к запуску
├── SELF_HOSTING.md        инструкция по запуску своей копии
└── DEPLOYMENT.md          заметки по размещённой версии
```

Подробнее о сервере: [backend/README.md](backend/README.md).

## Технологии

| Часть | Что используется |
| --- | --- |
| Веб-приложение | React 19, Vite, React Router, zustand, dnd-kit, иконки lucide |
| Сервер | Node.js 24, Express 5, Mongoose, Socket.IO, zod, helmet |
| База данных | MongoDB 8 (replica set) |
| Офлайн | Service worker и кеш в IndexedDB |
| Тесты | Встроенный тест-раннер Node, supertest, Playwright |
| Запуск | Docker и Docker Compose |

## Приватность

Никакой аналитики, рекламных трекеров и продажи данных. Размещённая версия использует
несколько внешних сервисов только для работы: хостинг, отправку почты, хранение картинок,
библиотеку фото для фонов и вход через Google. Своя копия может работать вообще без них.
Подробнее — на [странице о проекте](https://kanbanhub.app/about).
